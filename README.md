# 🏥 BMI-Calculator-App

An Android app built using MIT App Inventor that helps users 
calculate their Body Mass Index (BMI) instantly.

## 📱 What It Does
- User enters their height and weight
- App instantly calculates BMI
- Shows health category: Underweight / Normal / Overweight / Obese

## 🛠️ Built With
- MIT App Inventor (Block-based programming)

## 📲 How to Run
1. Download the `.aia` file
2. Go to [MIT App Inventor](https://appinventor.mit.edu/)
3. Click **Projects → Import project (.aia)**
4. Open and run on your Android device or emulator
